## 一、推荐版（信息最全，5 条，适合半页篇幅）

**智能家居边缘智能系统 —— 基于 YOLO 的边缘目标检测 Web 平台｜个人项目（AI 辅助开发）**
`Java 17 · SpringBoot 3 · MyBatis-Plus · MySQL · Python · FastAPI · YOLO11 · Vue3 · Vite · Element Plus · Git`

- 将原「STM32 + Linux 网关 + Qt + Python」嵌入式实训 demo 重构为 **Vue3 + SpringBoot + FastAPI + YOLO** 的 Web 全栈系统，设计「展示层 / 业务层 / AI 推理层 / 数据层」四层架构，用 HTTP + multipart 解耦 Java 与 Python 技术栈，三端独立部署、独立选型。
- 基于 **FastAPI** 封装 YOLO11 推理接口，接收上传图片并返回目标类别、置信度、边界框坐标等结构化 JSON；通过模型进程内 **单例缓存** 实现权重只加载一次，冷启动约 3s、热请求单次推理降至百毫秒级，并修正了原 socket demo 只返回首个目标的问题。
- 使用 **SpringBoot + RestClient** 完成业务层对推理服务的调用、原图存储与检测记录入库；基于 **MyBatis-Plus + MySQL** 实现检测历史分页、详情查询，配合统一响应体、全局异常处理和 springdoc 接口文档；独立排查并解决 RestClient HTTP/2 升级导致的转发失败（强制 HTTP/1）。
- 使用 **Vue3 + Element Plus** 实现拖拽上传、置信度阈值调节、检测历史表格与详情弹窗；用 **axios 拦截器** 统一解包响应，将模型像素坐标 **归一化为百分比** 在图片上叠加检测框并支持点击高亮，通过 **Vite 代理** 解决前后端跨域，并轮询展示两个后端服务的健康状态。
- 参与模型训练实践：对游戏画面视频抽帧并 **亲手标注 82 张图片、2 类目标**，基于 yolo11n 完成迁移训练（50 epochs，mAP50 0.975）；全程以 **AI 辅助编程（Vibe Coding）** 方式开发，本人负责架构与接口契约设计、AI 生成代码的审查、跨端联调与排错。

## 四、面试高频追问与回答要点（务必看完，防止翻车）

**Q1：这个项目是你独立做的吗？AI 写了多少？**
如实说：原嵌入式实训是老师带全班走一遍 demo；我把它 Web 化重构，三端代码大量借助 AI 生成，但**架构怎么分层、接口传什么字段、服务怎么连、出了 bug 怎么定位，都是我自己定的和亲手调通的**。能讲清每个模块为什么这么设计，就是你的项目。

**Q2：为什么用两个后端（Java + Python）？**
AI 推理生态在 Python（YOLO/ultralytics、PyTorch），业务系统主流是 Java（SpringBoot、事务、持久化、权限）。用 HTTP 解耦，各用所长、独立部署，推理服务以后还能单独扩容或换成别的模型。这是典型的「异构服务集成」，不是微服务（没有注册中心/网关，单体业务 + 一个推理服务）。

**Q3：检测框怎么画的？为什么坐标要归一化？**
YOLO 返回基于原图分辨率的像素坐标（左上角/右下角）。网页里图片会随容器缩放，直接用像素会错位，所以把坐标除以原图宽高转成百分比，用相对定位容器 + 绝对定位 div 叠在图上，任意缩放都对齐。

**Q4：为什么第一次请求慢、后面快？**
YOLO 权重加载（读图、初始化网络、首次 CUDA/CPU 预热）很重，约 3 秒。我在模块级用字典缓存模型实例，第一次加载后常驻内存，后续请求直接复用，单次推理只要一百多毫秒。代价是模型常驻占内存，重启服务后第一次仍会冷启动。

**Q5：mAP50 0.975 这么高，可信吗？（诚实红线）**
主动说明：这是实训小数据集（82 帧、2 类游戏角色），且验证集与训练集画面高度相似，指标偏乐观，不能代表泛化能力；我清楚它的局限。生产场景需要独立、多样、不与训练集重复的验证集。这样回答比硬吹更得分。

**Q6：阈值（confidence）有什么用？**
只保留置信度高于阈值的框。实测同一张图阈值 0.25 检出 5 个目标，0.8 剩 4 个，0.95 为 0——阈值越高越保守、漏检风险越大，越低召回越高但可能误检，需要按场景权衡。

**Q7：图片和数据怎么存的？**
原图按 `uploads/年月/uuid.jpg` 存磁盘（不入库，避免数据库膨胀），数据库表只存路径、模型、阈值、目标数、尺寸、耗时、结果 JSON 和时间；前端通过 SpringBoot 静态映射访问图片。

**Q8：跨域怎么解决的？**
开发环境用 Vite 的 devServer proxy，把 `/api`、`/uploads` 转发到 8080，浏览器看起来是同源；生产环境可由后端 CORS 或 Nginx 反向代理统一入口。

**Q9：密码/密钥怎么管理？**
数据库密码放在 `application-local.yml` 并写进 `.gitignore`，仓库里的 `application.yml` 不含敏感信息；`.gitignore` 同时忽略 node_modules、target、模型缓存、上传目录等。

**Q10（可选拔高）：前端打包有个 chunk 过大警告？**
Element Plus 全量引入导致主包约 1.2MB。优化方向是按需引入组件、路由级代码分割、gzip（已开启，gzip 后约 377KB）。学习项目先用全量引入换开发效率。
